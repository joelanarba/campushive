# **CampusHive**



CampusHive is a campus-focused digital platform that connects students with campus-based entrepreneurs and service providers (such as braiders, barbers, photographers, food vendors, and tutors). The platform provides a centralized space for service discovery, provider profiles, and appointment booking.



The folder structure is what is currently available; take note of this so you will distribute the code accordingly.



We're working on the backend; we'll be using CommonJS,



###### This is the API Style:

Architecture: REST

Data format: JSON

Transport: HTTPS

Backend: Node.js with Express

Database ORM: Prisma

Auth: JWT access + refresh token.



This is how our endpoints will look, e.g /api/auth/register, /api/auth/login



###### Naming convention:  plural nouns, lowercase paths, UUID identifiers, no verbs in URLs.
